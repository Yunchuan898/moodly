# 文档导航

从 [仓库首页](../README.md) 开始体验。这里按阅读任务组织文档；`product-design.md` 是产品决策的总入口。

| 想了解什么 | 阅读文件 | 内容与状态 |
|---|---|---|
| 先看项目全貌 | [提交评审摘要](submission-brief.md) | 目标用户、核心问题、演示范围、下一步 |
| 产品定义与范围 | [产品设计总纲](product-design.md) | 已确认决策、建议、待验证假设分别标注 |
| 需求与竞争 | [市场研究](market-research-2026-09-24.md) | 桌面研究；尚无用户访谈和竞品实测 |
| 首版如何接入 AI | [核心技术方案](core-technical-architecture.md) | 架构建议，尚未实施 |
| 代码已经做到哪一步 | [代码与需求对照](implementation-audit-2026-09-24.md) | 基于指定提交的静态审计，非实时功能清单 |
| 沙盘细节 | [沙盘设计规格](superpowers/specs/2026-09-24-sandbox-design.md) | 沙盘交互与实现边界 |
| 首次进入和安全提示 | [首次进入与安全须知设计](superpowers/specs/2026-09-24-onboarding-safety-design.md) | 功能分支的演示规格，不代表正式安全能力 |
| AI 方案备查 | [AI 情绪支持研究草稿](ai-emotion-support-research.md) | 早期调研草稿；其临床及效果表述须复核，不作为产品承诺 |

更新原则：功能状态以代码和明确版本为准；市场、临床和法规判断保留来源及限制；新决策同步回写产品设计总纲。
