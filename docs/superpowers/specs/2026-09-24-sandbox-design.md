# 沙盘 · 设计文档

日期：2026-09-24
状态：已确认，待实现
归属：moodly（心绪 · 情绪日记与自我关怀）子模块

---

## 一、目的

心绪解决的是「把情绪变成可以观察的天气」。但它全程依赖语言——「焦虑」「人际关系」「强度 4/5」这些词在说出口的那一刻，已经把体验压缩过一遍。有些东西在能被说出来之前就已经存在。

沙盘治疗（Kalff，源自 Lowenfeld 的 World Technique）的假设正好相反：**手比嘴更早知道**。不解释、不命名，只是把微缩模型摆进一个铺着沙的箱子里。世界出来了，意义留在当事人自己那里。

> **给心绪补上一个「不用说话」的出口。**

它和情绪日记是互补的一对，不是同一功能的两个皮肤：

| | 心绪日记 | 沙盘 |
|---|---|---|
| 媒介 | 语言 | 空间 |
| 时间 | 序列（最近 14 天） | 共时（一个世界） |
| 动作 | 记录 → 分析 → 发现规律 | 摆放 → 看见 → 留在心里 |
| 输出 | 结论 | **不输出任何结论** |

**它不是游戏，但它是玩的。** 明确不做：胜负、评分、成就、连击、排行、进度条。在一个沙盘里，最有破坏性的东西就是一个评判你摆得对不对的权威。

## 二、三条设计原则

1. **自由与受保护的空间** — 打开就是一盘空沙，没有「开始」按钮，不催任何事。沙具架安静地待在旁边。
2. **不解释** — 全程零象征解读。不出现「房子代表家庭」「水代表潜意识」这类话。这是卡尔夫学派的底线，也是伦理底线。
3. **只做见证** — 唯一的反馈是一句陪伴式邀请，不评价、不要求回答。

页脚声明：*这是一个自我陪伴的工具，不是心理治疗。如果你正在经历难以承受的时刻，请找一个人说说话。*

## 三、沙面引擎

「能挖沙」是本项目的灵魂。

**高度场**：128 × 96 的 `Float32Array`，每格 0–1 表示沙的厚度。初始为平沙（0.6）+ 静息噪声。0 = 挖穿，露出底下的水。

**安息角（angle of repose）** — 引擎中最关键的一段逻辑。每次挖/堆后跑数轮松弛：相邻格子高差超过阈值时，把多余的沙挪给邻居。没有它，挖出来的是垂直的假洞，手感像橡皮泥；有了它，坑壁会自己塌下来、沙丘有自然的坡度。**这是「沙」之所以是沙的唯一原因。**

**渲染**：逐像素 hillshading。内部 512×384（约 20 万像素），逐像素双线性采样高度场 → 梯度 → 法线 → 与固定光源点乘 → 查调色板 LUT。

- 调色板 5 档：`#2A2440`（深环境紫）→ `#6B5C74` → `#B9A585`（沙）→ `#E3D6B8` → `#FBF2DC`（高光）
- 受光面暖、背光面偏紫，接上心绪的暮色环境
- 水面：`h < WATER_LEVEL` 的格子按水深着色，浅处半透明可见沙，深处为 `#2D4468`，法线叠加正弦涟漪产生波光

**性能**：脏矩形增量渲染。笔刷只失效受影响区域（外扩 2 格供光照采样），`putImageData` 只更新该矩形，稳定 60fps。

**2.5D 观感**：沙面在 2D Canvas 上按俯视渲染，沙盘容器用 CSS 3D 轻微倾斜（`perspective` + `rotateX ≈ 52°`）。得到等距的立体起伏观感，实现只是一层 2D Canvas。摆件随同一容器倾斜。

## 四、沙具架

8 类共 48 个手绘内联 SVG：

| 类别 | 沙具 |
|---|---|
| 人物 | 男人 · 女人 · 孩子 · 老人 · 牵手的一对 |
| 动物 | 狗 · 猫 · 马 · 鸟 · 蛇 · 鱼 · 龟 · 蝴蝶 |
| 植物 | 大树 · 松树 · 花 · 仙人掌 · 竹子 |
| 建筑 | 房子 · 城堡 · 桥 · 塔 · 篱笆 · 门 |
| 自然 | 石头 · 山 · 贝壳 · 云 · 太阳 · 月亮 · 火 |
| 交通 | 汽车 · 船 · 飞机 · 火车 · 自行车 |
| 神话象征 | 天使 · 龙 · 暗影 · 宝箱 · 镜子 · 时钟 |
| 器物 | 钥匙 · 梯子 · 井 · 路灯 · 旗帜 · 书 |

统一 64×64 viewBox，底部对齐 y=64 作为「落脚点」。暖纸白描边 + 暮色填充 + 琥珀/淡紫点缀，任意缩放不失真、零外部请求。

## 五、交互

- **沙面**：工具栏切换「⛏ 挖沙 / ⛰ 堆沙」，笔刷三档大小，跟随指针的指示圈
- **摆放**：从架子拖到沙盘
- **调整**：点中摆件浮出工具条（⟲ 旋转 15° · ＋ 放大 · － 缩小 · 🗑 删除）；滚轮缩放、Delete 删除、拖出沙盘即删除
- **触屏**：pointer 事件统一处理，`pointerdown` 先 hit-test，命中摆件拖摆件，否则进沙面笔刷。单指可完成全部操作
- **投影**：每个摆件底部椭圆投影，大小与透明度跟随所在沙面高度。放在沙丘顶投影小而淡，放在坑底投影大而深
- **持久化**：草稿 debounce 自动存；「我的沙盘」可命名保存多件作品并附缩略图，按时间排列

**不做自动阶段判定**。卡尔夫说沙盘会经历混乱 → 挣扎 → 整合，但判定阶段是治疗师的工作且极易误伤。作品只按先后排开，让当事人自己看见。

## 六、与心绪的接法

沙盘完成后可选「记一笔此刻的心情」→ 写入同一 localStorage key，entry 标记 `from:"sandbox"` 与作品名。

`index.html` 改动仅三处：
1. 「自我关怀」区从 3 张卡片扩为 4 张，加「🪴 沙盘 · 摆一个世界」入口
2. `care-grid` 从 3 列改 2 列
3. 情绪日记条目中 `from === "sandbox"` 的显示标记「来自沙盘 · 作品名」

## 七、文件结构

```
moodly/
  index.html      现有（仅上述三处小改）
  sandbox.html    新增 · 沙盘页（结构 + 样式 + 装配）
  src/
    sand.js       沙面引擎：高度场 / 安息角 / hillshading
    shelf.js      沙具库：48 个内联 SVG + 分类
    scene.js      场景状态：摆放 / 变换 / 序列化 / 存档
    witness.js    陪伴式提问池
```

**用普通 `<script src>` 而非 ES module**——保持双击 `index.html` 即可运行（`file://` 下 ES module 会被 CORS 拦截，普通 script 不会）。各文件挂全局命名空间，延续项目「零构建、零依赖」的调性。

## 八、明确不做（YAGNI）

画廊式作品展示、导出图片、背景音乐/环境音、多套沙盘皮肤、自动解读、评分与进度。
