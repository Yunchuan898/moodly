# AI 数据告知与删除边界

2026-09-24。适用 `assist.html`、`src/agent.js` 和 `server/assist.py`。这份文件记录当前数据流，不是已完成的隐私政策或合规评估。

发送前，页面从 `/assist/info` 读取模型服务方名称、HTTPS 隐私说明和实际保留规则。配置缺失时禁止发送。用户需勾选同意；同意记录与告知版本、供应商及保留说明绑定，任一变化需重新同意。用户可以在交流页撤销授权。

每次发送包含本次消息、目标与策略、最多六条本页会话。额外上下文默认关闭，用户可分别勾选情绪记录摘要、已确认记忆或设备线索。日记原文、沙盘内容和联系人不会作为模型上下文发送。当前设备数字是演示数据，尚未连接真实设备。

本页会话仅在页面内存里；已确认记忆、待确认建议和同意记录保存在当前浏览器。记忆可查看、修改、逐条删除或清空。模型不能自行落盘。服务端不主动保存请求正文；外部模型服务方的保留规则由实际配置与服务方说明决定。清除本机数据不能撤回已发送请求。

明确自伤、自杀词句由规则分流为现实求助提示，不交给模型；规则可能误报或漏报。当前无诊断、治疗、实时监护、人工值守或自动联系亲友能力。迫在眉睫的危险可拨 120 或 110；12356 的具体服务时间以当地为准。
