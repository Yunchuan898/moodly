# 心绪 Moodly

面向 18–27 岁年轻人的情绪表达与自我整理产品原型。当前可体验的部分是情绪日记、自我关怀工具和非语言沙盘；AI 对话支持仍在设计阶段，尚未接入模型或后端。

## 快速体验

仓库是原生 HTML、CSS、JavaScript 项目，无需安装依赖。在仓库根目录启动静态服务：

```bash
python -m http.server 8000
```

浏览器打开 `http://localhost:8000/index.html`。首页可记录和回看情绪；从首页进入 `sandbox.html` 可使用沙盘。数据保存在当前浏览器的 `localStorage` 中，更换浏览器或清理站点数据后无法找回。体验时请勿填写真实敏感信息。

## 产品问题与当前范围

情绪波动发生时，用户往往希望先表达、理解自己，再决定是否采取行动。正式心理咨询是重要的外部选择，但预约、时间和费用可能成为部分日常情境下的门槛。心绪探索一条更轻的自助路径：**表达 → 回看 → 自主选择下一步**。

| 当前默认分支可体验 | 仍属方案或后续工作 |
|---|---|
| 情绪日记、历史回看、自我关怀卡片 | AI 对话、阶段编排、个性化策略与可控记忆 |
| 沙盘操作、作品保存与自愿关联日记 | AI 对沙盘内容的支持方式、服务端与模型接入 |
| 浏览器本地保存 | 跨设备同步、正式账号、可验证的效果评估 |

本项目不提供诊断、治疗或危机干预服务。当前原型的内容和规则未经过临床效果验证。

## 仓库结构

```text
index.html       情绪日记与自我关怀入口
sandbox.html     沙盘入口
src/             页面使用的原生 JavaScript 模块
docs/            产品、市场、技术、设计与实现对照文档
```

`main` 是默认展示分支；`feat/continuous-mood` 等分支包含尚未并入 `main` 的探索性实现。评估当前可用能力请以所打开分支的代码为准。仓库未配置构建系统或自动化测试。
