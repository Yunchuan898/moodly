# 心绪 Moodly

面向 18–27 岁年轻人的情绪表达与自我整理原型。登录后固定进入情绪日记主页；交流、沙盘、安全支持和设置都从主页进入。体验路径：**记录情绪 → 自由表达 → 选择本次对话目标 → 自主决定行动**。本项目不提供诊断、治疗或危机监护。

## 快速体验

在仓库根目录运行（需要 Python 环境）：

```bash
pip install -r server/requirements.txt
uvicorn server.assist:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000/`。首次设置称呼和口令后进入日记主页。当前标签内切换功能不用重复输入口令；关闭标签或在主页设置中退出后，再进入需要重新输入。日记、沙盘、记忆管理可本地体验。要启用真实 AI 对话，先按[后端配置说明](server/README.md)设置模型及供应商告知环境变量，再重启服务。缺少配置时交流页会明确提示，不能发送；没有伪装成 AI 的占位回复。

## 已有功能与边界

| 模块 | 当前实现 |
|---|---|
| 情绪日记 | 记录、回看、本地保存 |
| 沙盘 | 表达、保存作品；不自动解释作品 |
| 交流 | 四个可见目标按钮、最近本页对话、服务端有限策略、可跳过的行动建议 |
| 数据控制 | 发送前显示供应商与保留说明；日记摘要、记忆、设备线索逐项勾选；记忆可改可删可清空 |
| 安全边界 | 服务端高风险词句分流、输出规则拦截；规则未经专业审阅，不能作为临床安全能力 |
| 设备 | 接口与占位数据，尚未接入真实设备或微信运动 |

AI 对话会将本次消息、最多六条本页对话、目标和用户勾选的上下文交给配置的模型服务。日记原文、沙盘内容和联系人不会作为上下文发送。当前数据保存在浏览器 `localStorage`，本地账号口令不构成设备级安全保护。清除本机数据不能撤回已发给模型服务的请求。
